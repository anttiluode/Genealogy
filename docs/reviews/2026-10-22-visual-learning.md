## A visual line with three genuinely different tests

**Persistent interpretation — Model 5.** Model 4's frozen energy now accepts a transported memory plus precision. A compatibility check uses only currently visible pixels. A history that agrees with the present can change what the model paints behind an occluder even when the last visible frame is identical. Foreign-history trust rejection works (MSE returns to the last-frame-only 0.00568 long / 0.00622 short). H3's whole claim fails: putting history inside the energy improves long-hole MSE 0.000106 -> 0.0000764, but short-hole 0.00241 -> 0.00236 has ratio 0.980, failing 0.97. The model never observes scene changes confined behind the hole. H1b misses the preset +10 percentage-point threshold (79.2 -> 88.6%).

**Learning hidden constraints — ClaudeRepo1.** Rectified cross-band coincidences register beyond second-order signed spectra; the originally promising A2b result is not source independent (`skimage.data.cat` aliases `chelsea`), and all-ones weights do about as well as the learned average statistic. The later controlled two-world associative experiment gives genuinely experience-conditioned answers, but ordinary pixel ridge ties. Supplying a cubic feature gets 100% on a balanced three-way parity task while pairwise and linear models score 50%; product-feature ridge ties. More interesting: the browser's branch learner does not receive a preselected triple. Branches compete to self-predict their hidden member, and unsuccessful ones rewire. Across ten seeds per opposite synthetic world, all 20 learners find the correct eye–eye–mouth triplet (median 250 examples, range 62–1121) and answer correctly with masked mouth on 400 new scenes each. But the 3×3 slots, simple glyphs and noise scale are given. The MVTec LOCO anomaly-inspector design has no published LOCO test receipt here; do not call it passed.

**Transporting the mechanism to photographs — ModelImage.** V1 is a supervised-complete-scene prototype plus a jigsaw assignment, not a general image generator. V2 learns position-independent 16×16 patch codewords and pair/three-part context to *synthesize* truly omitted synthetic mouth pixels; 360 training scenes/world leads to 100/100 per world against 50/100 one-context controls. V3 progressively adds three exact pre-quantization image bands, competitive prototypes, learned spatial group candidates, restricted one-cell deformation, and visible-probe trust selection. Its tiny shifted-support fixture gets 4/4 versus rigid 2/4. Yet on 24 masked photo tests from four wholly unseen source photos it gets two-support hidden MSE 0.03756 versus untrained interpolation 0.00916; the trust check discards all 24 learned predictions. On 60 new synthetic face scenes V3 two-support 0.09019 also trails simple interpolation 0.05814, likely indicating alignment and conditional-detail bottlenecks. This does not invalidate V2's different 16×16 codeword setup.

## Cross-repository distinction

The older projects ask **what persists when direct sensory evidence disappears**. ClaudeRepo1 asks **which hidden conjunction can be discovered from experience**. ModelImage asks **whether that relation predicts pixels that were never supplied at inference, especially away from the training generator**.

A learned memory of previously seen pixels, a supplied algebraic conjunction, a discovered toy conjunction and a natural-image visual prior are not interchangeable achievements. The substantive next discriminator is a disjoint-photograph completion task where learned joint multiscale groups beat interpolation, fixed-/single-group versions and a strong convolutional patch baseline under matched memory and compute. Pre-register the natural-image holdout by source photograph, exclude alias duplicates and report failures.
