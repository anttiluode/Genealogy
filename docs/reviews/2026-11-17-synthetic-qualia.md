## What is actually inherited

QualiaClaude → WaveComputer is physical wave-body code ancestry; QualeX → WaveComputer is an implemented **idea** extracted from a written proposed unit. WaveComputer → WaveComputerAstra extends to addressed two-hop testing; WaveComputer → ApicalRuleReversalMachine adds fast multiplicative context; WaveComputer + ARM → WaveCortex fuses both circuits. Astra → WaveCortex is experimental discipline and controls, **not** its addressed two-hop code. All these → SyntheticQualia are *paper synthesis* edges, not a new test of the full combined system.

The observed results do not mean all six functional properties occurred in one general learned world. The distinctive combined WaveCortex achievement is one hidden sign rule inferred from surprise and propagated through an imagined B to C. The first QualiaClaude cross-sense revision was additive; Q8 requires binding an actual *common cause* across modalities and is still open.

## Negative transport result and Moon comparison

The field is linear; its site × lag Green's function preserves wave propagation exactly within the supported model. On discrete point-to-point chains the field introduces costs and cross-talk, and scalar copies with comparable local logic are more accurate. That is a bounded claim about these tasks, not a statement that wave media can never calculate.

[Moon](https://github.com/anttiluode/Moon) is a useful **conceptual** relative: its hand-written light-transport network approximates scattering geometry, but none of the five new repos inherits Moon code. Writing ideal WaveCortex weights by a Moon-style least-squares solve against the known kernel remains an **untested suggestion**; it cannot yet be said to correct the 0.64 slope.
