# Visualizers & interactive demos

**Genealogy's visual side** · [Open the Genealogy wall](https://anttiluode.github.io/Genealogy/#visualizers) · Updated 13 November 2026.

These are **browseable projects and visual-instrument ideas**, not a scientific ranking or a statement that every project has a running online demo. Where a verified browser page is known, it is linked separately. Repositories can be experimental, visual art, or simulation; an attractive plot is not proof that an AI mechanism works.

## Honest ancestry and a live slot for future work

- **Entrain (July)**: physically modeled oscillators driven by measured sound. In the census already; curated here for visual discovery. No demonstrated code reuse in either Korva or MusicVisualizer1.
- **Korva (November 12)**: rhythm-memory organ and trained small transformer; it is not itself a six-world renderer.
- **MusicVisualizer1 (November 13 revision by Astra)**: retains Korva's engine and weights, but uses an independent audio-responsive graphics pipeline. Its Fourier Bloom, Phase Loom and Resonant Cortex worlds credit visual ideas from earlier experiments rather than importing the underlying models.
- **Still baking with Astra:** future visualizer iterations should get individual records when their repository/version and actual behavior are known, rather than being claimed here before release.

This directory is a curated navigation layer over the much broader [repository census](https://anttiluode.github.io/Genealogy/#view-census). Scientific tests and limitations remain with the original repositories and their dated archaeology passes.
