# Research log

## 2026-09-15 — first archaeological scaffold

This first graph is intentionally sparse. The repository census and the genealogy are different objects: a repo can exist in the census without receiving a lineage edge until there is evidence.

### Strong first-pass findings

- **PhaseStigmergy → FunctionalArbors** is a real lineage: the later arbor work explicitly reuses a PhaseStigmergy-style Laplacian/opportunity growth process, while keeping the negative phase-specific results visible.
- **Operaattori → OperaattoriJako** is an unusually clean extraction: a broad morphology-to-operator study produced a small reusable transport-vs-feedback diagnostic.
- **Geometric-Neuron → GeometricNeuronV24** is a correction lineage: V24 strips away the old thermostat story and keeps the addressable-observation problem.
- **GeometricNeuronV24 + TinyAvatar2 → ReadWrite** joins sensing and intervention as `M J`.
- **LentoOrava** is the strongest practical extraction in the current AI/neuron spine because its scalar intervention idea became PulseTriage rather than remaining only an analogy.
- **AnttisNeuron → GrowingAnttisNeuron → ActiveVectorNN → NewMachine → FusionMachine** is now unusually explicit in the repositories themselves. The conceptual center shifts from dendritic modes to developmental routing, then resident-state/event separation, then state repair/publication, then late relevance and routed writes.
- **Clockfield** belongs in the atlas partly because its direct adaptive-weight-decay test was negative. `ClockfieldMeetsGeometricNeuron` then became a useful example of a grand unification being progressively narrowed by operator, pinning and topology falsifiers.
- **Kompressori** is a model case of failure producing a better object: partial-field reconstruction mostly failed, revealing response geometry and then low-rank operator updates as the more interesting quantity.

## First atlas slice status

The first curated scaffold contains 28 reviewed nodes across practical tools, Clockfield, Geometric Neuron/bounded observation, morphogenesis, operator response, splat/world representation, search/routing, and the recent AnttisNeuron→FusionMachine line. It intentionally leaves the majority of the corpus in the census rather than inventing ancestry.

The static explorer uses deterministic family columns rather than a force simulation. This is a research choice: the purpose is to inspect evidence and corrections, not to produce an impressive graph-shaped cloud.

The public census is generated separately by `scripts/refresh_repos.py`. In environments without outbound DNS the script fails without overwriting existing data; GitHub Actions is the canonical refresh environment.
